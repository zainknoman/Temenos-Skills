| 46 | `POS.TXN.IFRS.DEAL.PL.LCY` | `PosTransaction_IfrsDealPlLcy` | TField |  | Stores the Net Present Value of the Un-realised Profit or loss in local currency till todate after discounting. No Input field. Automatically updated by the system when the FOREX transaction is revalued through IFRS revaluation method. The discounting is done at NPV.RATE either under Simple Method or under Compound Method. The NPV RATE for LOCAL currency is derived from the PI table with the key specified in REVALUATION.PARAMETER. The formulae for simple and compound method of discounting are: Simple Method: NPV = Deal Profit or Loss/ (1+ r/100 * n/365) Compound Method: NPV = Deal Profit or Loss/ [(1+ r/100) to the power of n/365] Where ' r ' is the rate of interest from the PERIODIC.INTEREST Table and ' n ' is the number of days the value date is from the Spot Date as on run date and 365 is the basis (The basis is as applicable to the Local Currency.) If the Value Date of the deal falls within the Spot Period for the currency pair, then no discounting is done. If the Value Date falls within one year from the Spot Date for the currency pair, discounting will be done under Simple Method. If the Value Date falls beyond one year from the Spot Date for the currency pair, discounting will be done under Compound Method. The Spot Date for the currency pair will be reckoned as on run date. The year is always calendar year. For more details, Please refer to User Guide for FOREX Application. |
