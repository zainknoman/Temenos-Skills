When individual deal details are displayed in an enquiry based on the customer position file, the details of the application to view should be defined in this field. An existing application, or Version of an application should be defined. Applications can be identified by the I-descriptor EB.SYSTEM.ID which extracts element 3 of the CUSTOMER.POSITION key. Alternatively the CATEGORY.CODE could also be used to identify the application. CONVERSION @ E.CUS.POS.NEXT.LEVEL --------------------------------- Within CUSTOMER.POSITION enquiries the conversion routine @ E.CUS.POS.NEXT.LEVEL can be used to define the next level for drilldown. This performs the following processing: The element DETAIL.NEXT.LEVEL should be defined either as a SELECTION field or as an element in the ENQUIRY record. IF the value associated with this is not "NO" then: - For system id = AC the enquiry STMT.ENT.BOOK will be used. This will show the entries accross the account for the last 7 working days, unless a number of days is defined in the SELECTION AC.NO.DAYS, in which case this number of days will be shown. - For system id = SC the enquiry SC.SEC.ACC.HOLD.SUM will be used. This shows all securities held for the portfolio. - For all other applications the underlying application record will be displayed according to the defininition of this field. If no relevant record applies, the APPLICATION defined in the EB.SYSTEM.ID record will be used if present. If the DETAIL.NEXT.LEVEL value is NO: - If the Limit referenc in the CUSTOMER.POSITION key is SCPORT, the enquiry SC.PORT.HOLD.SUM will be run for the customer. - A limit reference beginning CURR will run the enquiry ACCT.BAL.LAST to display the accounts held for the customer. - A limit reference of COLL will run enquiry CO.001 for the customer to display collateral details. - A limit reference of COMMIT will run the enquiry LD.COMMITMENTS to show commitment contracts held by the customer. - A limit refernce of type FX will run FX.ENQ.SUMMARY to show FX deals held by the customer. - A global limit reference will run the enquiry LIAB showing all limits. - All other limit reference values will run LIM.TXN to show limit details. Details are returned to the enquiry in the following format: Next application / enquiry "&gt;" Selection 1 "&gt;" Selection 2 "&gt;" Selection 3 Where Application / Enquiry contains either: Application Name S id (E.g FOREX S FX9501212345) for an application or STMT.ENT.BOOK Selection 1 to 3 contains the required selection criteria for the next level enquiry, and is null for application drilldown.
