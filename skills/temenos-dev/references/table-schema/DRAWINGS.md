| 1 | `TF.DR.DRAWING.TYPE` | `Drawings_DrawingType` | TField | Yes | This field displays a code to specify what type of drawing this is. This code identifies which kind of Drawing is being made under the L/C, and will impact the kind of processing done. The following types can be entered for a new drawing: AC - Acceptance (Usance credits) DP - Deferred Payment (Usance credits) RP - Release Payment SP - Sight Payment CO - L/C Collection The following types can only be entered as a change to an existing drawing: CC - Collection Chase CR - Collection Rejection FR - Final Rejection MA - Matured Acceptance MD - Matured Deferred Payment. RD - Registration of Documents DC - Document Checking AD-Amendment to drawings (only SP/MA/MD drawings can be amended using AD) SG - Shipping guarantee is issued under an import Letter of Credit. Can't be created manually. Draw type can be changed to SP, AC or DP only. For Drawing types of 'AC' and 'DP', a term or usance credit is established whereby the funds will be debited and paid on the MATURITY.REVIEW date specified later. If the funds are required to be paid before this date, the Drawing can be Discounted, whereby payment is made on the Value date specified, but reimbursement is obtained on the MATURITY.REVIEW date. If 'SP' is entered, then both Payment and reimbursement is made on the VALUE.DATE specified. For 'AC' and 'DP' type drawings, once the maturity review date is reached and the drawing undergoes maturity processing, then the Drawing type will automatically change to 'MA' (From 'AC'), and 'MD' (From 'DP'), indicating that these deals are now matured. However, it is to be noted that for Export Usance Drawing to Mature automatically, either the CONFIRM.INST in LC should hold the value as CONFIRM or the Drawing must have been discounted. In absence of either of these the Drawing has to be manually matured. In the case of Import Usance Drawing is maturity is always automatic with an option for the user to manually mature the same. If an authorised 'CO' is changed to a 'CC', then the system will perform chasing logic (ie. produce chase advices), and the reset the drawing type back to its original value, once authorised. When a drawing type of RP is used for an Export LC, this will generate a message (MT754) acknowledging documents were presented in accordance with the terms and conditions of the underlying credit and also a claim for reimbursement (MT742). Alternatively, an Import LC will generate the release of a payment, to the beneficiary, in the form of a Customer Transfer (MT100). A Final Rejection (FR) is normally used when the Sender considers the documents, not to be in accordance with the terms and conditions of the credit, and consequently, refuses them. The difference between drawing type FR and CR is that using type CR will generate a message denoting advice of refusal (MT734) and FR will only ever generate a letter denoting Advice of Refusal/Rejection (1734). Note that this drawing type may only be used following a Collection Rejection (CR). Amendment to Drawing (AD) is permitted to facilitate messaging activity by enabling to alter text and/or local fields. When the field REDUCE.LC.LIAB in MD.PARAMETER is set to 'Yes', 'SG' type of Drawings are created under import LC. Can't be created manually. Draw type can be changed to SP, AC or DP only. Note : Neither a type FR or RP will reduce Drawings limits. Validation Rules: 2-2 type AAA (Alpha) characters. Valid codes are: 'AC'; 'DP'; 'RP'; 'SP'; 'CO'; 'CC'; 'CR'; 'FR'; 'MA'; 'MD';'AD'. (Mandatory Input) RP may be used irrespective of the type of the underlying LC. If the type of L/C is a sight payment, then the only valid inputs to this field are:- 'SP', 'CO', 'CC', or 'CR'. If the type of L/C is a usance or term payment, then the only valid inputs to this field are:- 'AC', 'DP', 'CO', 'CC', or 'CR'. 'CR' can only be entered if the drawing has been previously authorised as 'CO'. 'FR' can only be entered if the drawing has previously been authorised as 'CR'. Next stage after registering documents "RD" must be "DC". Draw type "DC" can be changed to "CR","RP","SP","AC","DP" depending upon the LC type |
