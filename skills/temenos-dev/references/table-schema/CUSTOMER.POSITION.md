| 8 | `CUP.LIMIT.LEVEL` | `CustomerPosition_LimitLevel` | TField |  | Denotes the level of the Limit record from which the data was extracted. Transaction data is extracted at both PRODUCT and SUB product level (although not at Global level), so a single transaction may appear twice in the CUSTOMER.POSITION file with 2 different limit references in the key.
