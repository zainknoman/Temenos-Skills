| 25 | `I9.PAR.RECOVERABLE.VAL.OPTION` | `IfrsParameter_RecoverableValOption` | TField | No | This field holds options which identifies how collateral has to be considered in Expected Credit Loss(ECL) calculations. As per IFRS 9, collaterals will be mostly covered as part of LGD itself. However Transact solution provides only a framework to upload these LGD values, the LGD values used in the ECL calculations may or may not include collateral. Hence these options have been introduced. Expected Credit Loss(ECL) is the difference between Exposure At Default(EAD) and Recoverable value. ECL = EAD - Recoverable Value. EAD = NPV of Contractual cashflows + Pastdue. Where NPV is Net Present Value. Recoverable Value calculation differs for each of the options mentioned here. Allowed values for this field are COLL.IN.LGD, UNSEC.EXP.CF.COLL or EXP.CF.COLL COLL.IN.LGD - Collateral value is already included as part of LGD calculation. No need to consider collateral values explicitly in ECL calculations. Recoverable value = NPV of Expected Cashflows. Where NPV of Expected Cashflows = EAD * (1-PD*LGD) For below two options, Collateral value is not included as part of the LGD calculation. Hence we need to consider collateral values explicitly in ECL calculations. UNSEC.EXP.CF.COLL - Collateral is mitigated on the exposure amount of the contract and then we compute loss amount(ECL). Recoverable value = NPV of Unsecured Expected cashflows + Collateral value. NPV of unsecured expected cashflow = (EAD - Collateral value)(1-PD*LGD) . Where PD is probability of Default and LGD is Loss Given Default. Simpler way, ECL = (EAD - Collateral value)*PD*LGD EXP.CF.COLL - First we compute loss amount(ECL) and then Collateral is mitigated on the loss amount of the contract. Recoverable value = NPV of Expected cashflows + Collateral value. Simpler way, ECL = (EAD*PD*LGD) - Collateral value Validation Rules: Default option is COLL.IN.LGD Optional input. |
